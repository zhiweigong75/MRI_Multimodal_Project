# Skill: repo-audit

Use for repository-wide inspection before major work, figures, presentations, or cleanup.

## Inspect

- repository tree
- Git status
- tracked vs ignored artifacts
- configs
- experiment registry
- project state
- tests
- Slurm scripts
- source modules
- result summaries

## Report

1. current project structure
2. source-of-truth files
3. duplicated/ad-hoc scripts
4. stale or conflicting configs
5. missing provenance
6. untracked scientific assumptions
7. large/generated files that should not be in Git
8. recommended cleanup order

Do not reorganize the repository automatically unless explicitly requested.
