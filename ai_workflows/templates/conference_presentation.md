# Conference Presentation Prompt Template

## Audience
Scientific conference audience

## Target duration
TODO minutes

## Story
Clinical/scientific problem → gap → core insight → method → key evidence → contribution → why it matters

## Requirements
- Do not narrate the full experiment history.
- Lead with the problem and contribution.
- Use only the strongest evidence necessary for the claim.
- Keep the method figure scientifically faithful.
- Avoid internal project bookkeeping on main slides.
- Preserve detailed ablations in appendix.
- Speaker notes should sound spoken, concise, and confident without overstating evidence.
